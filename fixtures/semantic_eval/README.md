# Воспроизводимое испытание семантики

Корпус содержит 14 синтетических SAS-программ: 12 преобразований с контрольными результатами и 2 задания, требующие отказа. Для каждой программы зафиксированы четыре набора входов: граничный, два с дополнительными случайными строками и перемешанным порядком загрузки, пустой.

`frozen/corpus.json` и `oracles.py` зафиксированы до первого платного вызова. Их SHA-256 находятся в `frozen/manifest.json`; исполнитель проверяет оба хеша. Модель получает полный исходник, схемы, ограничения и целевую СУБД. Строки входов и контрольные результаты ей не передаются. Один ответ модели исполняется без изменений на всех четырёх наборах. Сравниваются все объявленные выходы, значения, повторяющиеся строки и семейства типов.

Эталон написан отдельно на Python по заявленной семантике. Нативный SAS не запускался. Ни положительные проверки, ни успешный ответ модели не разрешают гейт 2.

## Стенд

`docker compose -f fixtures/semantic_eval/compose.yaml up -d` запускает отдельную PostgreSQL 17.10 на 127.0.0.1:55439. Образ закреплён digest, автоматическая загрузка отключена. Нужен уже имеющийся локальный образ. База и пароли учебные; корпоративных источников нет.

SQL выполняется от ограниченной роли с правом создавать только временные объекты. Каждое исполнение заканчивается ROLLBACK. Загрузка вымышленных входов и эталонов выполняется отдельным владельцем только в базе `semantic_eval`.

## Платный эксперимент

`python -m tools.run_semantic_eval --data LOCAL_LEDGER --model-config LOCAL_PROFILE --out evidence/semantic-eval-20261106 --phase NEW_PHASE --prompt fixtures/semantic_eval/revised_prompt.txt`

Параметр `--thinking enabled --max-output 12000` включает отдельную проверку режима рассуждения. Требуется локальный профиль с разрешённым endpoint и защищённым ключом. Ключи в пакет не входят. Переменная `SAS_MIGRATION_DB_PASSWORD` задаёт пароль учебной проверяющей роли.

Скрипт использует общий для фаз журнал расходов с лимитом $0,85; максимальная стоимость резервируется до запроса. Автоматических платных повторов нет. Существующая запись фазы и сценария, даже незавершённая, повторно не вызывается. Для нового эксперимента требуется отдельное явное имя фазы. Не удаляйте журнал для обхода лимита.

Публичный профиль принимает только SHA-256 этих синтетических архивов. Пользовательские EGP не добавляются в список разрешённых файлов.

## Что не покрыто

Не проверены Greenplum, ClickHouse, нативный Enterprise Guide, корпоративная модель, реальные данные, производительность на больших объёмах и полный SAS. Архивы EGP минимальны и проверены импортёром приложения; совместимость с нативным EG не заявляется. LIBNAME, произвольные форматы, динамические макросы, массивы, hash objects, MODIFY/UPDATE и внешние побочные эффекты требуют отдельных корпусов.
