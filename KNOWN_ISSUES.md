# Ограничения пробной версии

| Область | Ограничение и действие |
|---|---|
| Корпоративный сервер | Реальную доступность через корпоративный VPN, proxy и CA проверяйте кнопкой «Проверить соединение» на рабочем компьютере. Проверки локального сервера и синтетического публичного профиля подтверждают только соответствующие маршруты. |
| Тарификация | При неизвестной цене разрешён каталог, запуск генерации блокируется до выбора подтверждённого режима. Резерв запроса сохраняется при неизвестном usage. |
| Профили | Разные диалекты могут завершиться с разными статусами. В частичном пакете есть явный список целевых профилей. Общий гейт требует прохождения всего утверждённого объёма. |
| ClickHouse | Детерминированная правка Nullable охватывает подтверждённые типы и ограниченные выражения. Сложные случаи требуют уточнённого контракта или ревью. |
| Исполнение | Нативные PostgreSQL и ClickHouse используются в синтетической лаборатории. Исполнение Greenplum и сверка с SAS Institute остаются отдельными проверками. |
| SAS | Синтетические EGP проходят импорт приложением. Совместимость архивов с нативным Enterprise Guide и универсальная поддержка SAS пока не подтверждены. |
| Ключ | DPAPI защищает сохранение для текущего Windows-пользователя. При недоступности DPAPI используйте ключ только на сеанс. |
