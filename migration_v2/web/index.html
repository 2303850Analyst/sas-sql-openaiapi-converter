Внешние значения фиксируются в ревизии. Вычисляемые по данным значения переводятся вместе с SAS-логикой, без подстановки догадок.

Эти условия влияют на результат. Подтверждайте их по способу загрузки данных; неизвестные условия нельзя угадывать по названию поля.

Задачи и покрытие исходника
Обязательные выходы и промежуточные таблицы SQL-пакета
Без библиотеки или WORK. - временная таблица. Явная схема сохраняется. Укажите порядок столбцов результата.
Входные источники сохраняются. TEMP не получают суффикс. При изменении существующей выходной таблицы сначала создаётся отдельная тестовая копия. Изменение режима требует нового согласования.
WORK / временные таблицы
По умолчанию WORK и имена без библиотеки создают TEMP. Здесь перечислены все такие выходы; для каждого можно дополнительно выбрать схему/БД и имя.




Вопросы к исходной логике
Подтверждайте только после просмотра исходника. Ошибку чтения или динамический источник нельзя закрыть комментарием.




4. Генерация и проверка SQL
Модель получает смысловые задачи с оригиналами SAS, нужными макросами и контрактами. Затем отдельный вызов проверяет перевод. Эталоны сравнения ей не передаются. Генерация запускается только кнопкой.


Задачи и решения HITL
Исправление SQL сохраняет гейт 1 при неизменном контракте. Новый результат должен пройти отдельное ревью.
Денежный лимит профиля сохраняется.


Ручное редактирование кандидата и подробности
Локальное задание содержит оригиналы. Публичный тестовый API принимает только зарегистрированные вымышленные проекты.
Приёмка кода требует актуальных статических и ИИ-проверок. Она не подтверждает исполнение или совпадение данных с SAS.


Оригиналы и ревизии сохраняются локально. Статический успех не подтверждает совпадение результатов SAS и SQL.
