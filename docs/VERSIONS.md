# Основания версий

Версия продукта относится к UI и контракту команд. Версия SQLite меняется при несовместимом хранении. Контракты и таргеты закреплены хешами утверждённого плана. Состав правил имеет отдельный содержательный fingerprint. Ревью хранит хеш prompt, а проверка данных - хеш политики сравнения. Сборка фиксируется Git commit и SHA файла EXE.
