# Состояние SAS → SQL V2 на 10 ноября 2026

| Область | Состояние |
|---|---|
| Поставка | Windows EXE 0.3.0 доступен как пробная сборка. Изменения и результаты проверок находятся в draft PR #1 |
| Подготовка | EGP импортируется локально. Контракт хранит исходные блоки, порядок, параметры, типы, входы и выходы. Привязки источников и назначения задаются явно вне модели |
| WORK и Testifier | TEMP по умолчанию, реестр и ручной выбор назначения. Тестовый режим добавляет `_test` постоянным выходам. Нативный контроль PostgreSQL проверяет сохранность оригинала |
| Модель | OpenAI-compatible профиль, DPAPI или ключ на сессию, каталог и синтетический пробный вызов. Kimi проверен на синтетике. Корпоративный endpoint ждёт проверки |
| Выпуск | Статика, независимое ревью, ревизии, два гейта, полный или ограниченный экспорт. UNION ALL и APPEND FORCE приняты в пробной сборке |
| Нативные результаты | PostgreSQL и ClickHouse подтверждены для принятых синтетических выходов. Для Greenplum есть статика и ревью кода. Нативного Greenplum и SAS Institute в этой серии нет |
| BI | Superset вернул сырые строки принятого APPEND FORCE. Нормализация используется в сравнении. Риск округления крупных десятичных чисел в BI подтверждён отдельно |
| Незавершённые случаи | Полный flow, сочетания KEEP/WHERE/RENAME, часть многовыходных сценариев и динамические параметры. Реальные проекты требуют согласованных исходников, сопоставлений и эталонов |

Для ближайшей приёмки нужен один полный маршрут на Greenplum с эталонными данными и подтверждением всех выходов. Затем - один согласованный реальный EGP. Регулярные процессы с зависимостью макросов от времени или результатов SQL требуют отдельного сценария исполнения.
